# 🦷 Starz Dental Hospital Website

A modern, responsive dental clinic website built for **Starz Multi Specialty Dental Care**.  
The website provides patients with detailed information about dental services, clinic details, doctor profiles, and a convenient online appointment booking system.

---

## 🚀 Live Website

*starzdental.in*

---

## 📌 Features

- 📱 **Fully Responsive Design:** Optimized for Mobile, Tablet, and Desktop displays.
- 🎨 **Modern Dental UI/UX:** Clean, accessible, and intuitive patient experience.
- 📄 **Core Pages:** Home, About, Services, Gallery, and Contact pages.
- 🦷 **Services Showcase:** Highlights treatment options with detailed descriptions.
- 🖼️ **Before & After Gallery:** Visual portfolio of treatment results.
- ⭐ **Patient Testimonials:** Interactive reviews section.
- 📅 **Appointment Integration:** Easy scheduling for clinic visitors.
- ⚡ **High Performance:** Smooth transitions and fast load times built with React & Vite.

---

## 🛠️ Tech Stack

### Frontend
- **React.js**
- **Vite**
- **Tailwind CSS**
- **JavaScript (ES6+)**

### Libraries & Tools
- **React Router** (Navigation)
- **Swiper.js** (Sliders & Carousel)
- **Lucide React** (Icons)
- **Firebase / Supabase** (Backend & Form Submissions)

## ⚙️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ayman047/Starz-Dental.git
   ```

2. **Navigate into the project directory**
   ```bash
   cd Starz-Dental
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the local development server**
   ```bash
   npm run dev
   ```

5. Open your browser and visit:  
   `http://localhost:5173/`
